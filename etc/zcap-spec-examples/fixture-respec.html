Delegation

A root capability looks like this:

Example 1 
{
  "@context": "https://w3id.org/zcap/v1",
  "id": "urn:zcap:root:https%3A%2F%2Fexample.com%2Ffoo",
  "controller": "did:key:example",
  "invocationTarget": "https://example.com/foo"
}

With a comment, which makes it non-strict-JSON:

Example 2
{
  "@context": "https://w3id.org/zcap/v1",
  // populated via a database or external system call
  "controller": "did:key:example",
  "invocationTarget": "https://foo.example/collections/123"
}

An HTTP invocation, and an entity-heavy body:

Example 3
POST /foo HTTP/1.1
Host: example.com
capability-invocation: zcap id="urn:uuid:1234"
X-Note: 5 < 10 && 10 > 5 — ok ✓
